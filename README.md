# 📊 Data Science and Statistics

A collection of **Data Science and Statistics practicals implemented using Python and Jupyter Notebook**.

This repository contains hands-on experiments covering data acquisition, statistical analysis, data preprocessing, visualization, and fundamental Machine Learning algorithms.

### 📈 Data Science & Statistics
- Data Acquisition
- Measures of Central Tendency
- DataFrames
- Missing Value Treatment
- Data Preprocessing
- Data Visualization

### 🤖 Machine Learning
- Simple Linear Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest

- Collecting and understanding data
- Cleaning and preprocessing datasets

- Creating meaningful visualizations
- Understanding Machine Learning algorithms
- Building basic predictive models

```bash

```

### 2. Open the project

```bash
cd DATA-SCIENCE-AND-STATISTICS
```

### 3. Install required libraries



Open any `.ipynb` file and run the cells sequentially.
